YASWANTH R — PORTFOLIO WEBSITE

HOW TO RUN
1. Extract this ZIP file.
2. Keep index.html, style.css and script.js in the same folder.
3. Keep your photo at: assests/Yaswanth Photo.jpg
   (The folder name is intentionally spelled 'assests' to match your existing HTML.)
4. Double-click index.html, or open the folder in VS Code and use Live Server.

PERSONALISE BEFORE PUBLISHING
- In index.html, replace https://www.linkedin.com/ with your actual LinkedIn profile URL.
- Replace your.email@example.com in the mailto link with your real email address.
- Check project descriptions, certificates, and dates for accuracy.
- To change the photo, replace the file at assests/Yaswanth Photo.jpg.

FILES
index.html  — page content and sections
style.css   — colours, background, layout, responsive design and animations
script.js   — mobile menu, scroll progress, reveal animations and photo fallback
